## 本篇主线

回答两个问题：**IM 技术是什么、为什么值得每个后端学一遍**——IM 是所有"实时互动、高实时性"场景的底层基础设施；IM 系统是前后端技术的综合体，深度覆盖网络、数据库、缓存、加密、消息队列、分布式、高并发、一致性，学 IM 即系统化遍历一遍后端经典实践。

## 高频金句

- 所有需要"实时互动""高实时性"的场景，都需要、也应该用到 IM 技术。
- IM 并不是一门仅限于聊天、社交的技术，它已经广泛运用于我们身边形形色色的软件中。
- IM 技术是众多前后端技术的一个综合体，只不过因使用场景的不同，在某些技术点上有更多侧重。
- 我们要打造的是一套"实时、安全、稳定"的 IM 系统。
