## 本模块主线

在基础能力之上做通用性优化：**通道与媒体**（13 复杂网络下的通道高可用、14 分片上传加速发送、15 CDN 加速浏览播放、16 对接 APNs 等第三方系统级通道）→ **性能与规模**（17 多级缓存抗热点、18 Docker 容器化水平扩展、19 端到端 Trace 监控、20 万人群聊的存储与并发）→ **实战与答疑**（21 期末实战补齐长连接与 ACK/心跳、22 五个代表场景的架构异同答疑）。这一篇的方案大多不限于 IM，适用于大部分后端服务架构。
