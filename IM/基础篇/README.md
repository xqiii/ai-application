# 基础篇（01~08 讲）

> 极客时间《即时消息技术剖析与实战》袁武林 · 第一模块
> 课程主页：https://time.geekbang.org/column/intro/225
> 总大纲见 [../OUTLINE.md](../OUTLINE.md)。

## 本模块主线

回答一个问题：**一套能用的 IM 系统由什么组成、四大特性怎么逐一落地**。01 给出全景：五大组成（客户端 / 接入服务 / 业务处理服务 / 存储服务 / 外部接口服务）与"接入层、业务层必须拆分"的缘由；02 落到实现（三张表 + 收发链路 + 两级未读数）；之后按四大特性逐一攻坚——实时性（03 轮询→长连接）、可靠性（04 ACK）、一致性（05 序号生成器）、安全性（06 HttpDNS + TLS），再补两个横切实战：未读数的原子变更（07）与长连接保活（08 智能心跳）。
