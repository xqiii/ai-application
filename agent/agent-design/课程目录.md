## 导航操作要点

1. 每次 MCP js 调用先 bootstrap（browser-client.mjs via ZCODE_PLUGIN_ROOT）+ getForUrl + tabs.list（独立调用）
2. 第二次调用：tabs.get(id) → getByText("目录项文本前缀").count()===1 → scrollIntoView({block:"center"}) → 重新 getBoundingClientRect → cua.click(中心坐标) → waitForTimeout(2500) → verify url/title → evaluate 提取 #article-content-container innerText（按"全部留言"截断）
3. 点击失败时：不要重试同一 locator，重新检查可见性和坐标
