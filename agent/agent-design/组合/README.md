## 核心方法

**选型五步**：① 说清任务怎样算完成、哪些不能做 → ② 现有程序或最小方案走一遍看哪步做不到 → ③ 针对困难选少量候选、同一批任务比较 → ④ 不只看有没有办成，还要看有没有增加原来不会犯的错、时间费用能否接受 → ⑤ 记录决定并写明哪些部分还没验证。

**三步判断引入什么**：
- 意图模糊 → 模型理解诉求（其余仍由程序控制）
- 事实缺口（如发票未知）→ 转人工补事实，**不是加一次模型评审**（缺的是经过核实的事实，不是更多推理）
- 经常需要临时安排步骤 → 才考虑规划执行

**"下一步由谁决定"**：固定流程（程序）→ 边查边决定（模型）→ 规划执行（模型提计划、程序保存检查推进）。

## 高频金句

- 学过设计模式，不意味着每创建一个 Agent 都要多加几个模式。（41）
- 程序不应该因为没有退成钱，就认为自己失败了。（41）
- 缺的不是更多的推理，而是一条经过核实的事实。（41）
- 模式的增加代表着复杂性也随之提升——只有当任务确实需要，增加的工作才有必要。（41）
