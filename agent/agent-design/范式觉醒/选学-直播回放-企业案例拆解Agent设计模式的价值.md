## 一句话总结

上海东方屹腾科技的 Agent 化转型实践证明：企业执行型 Agent 光靠 MCP 不够，需要"Plan-and-Execute + Minimal Tool Set + 确定性绑定 + 护栏"；双轴框架能直接映射生产架构（控制面/叙事面分离、草稿纸、分层记忆 L1/L2/L3）。

## 通用开放 Agent vs 企业执行型 Agent

| | 通用开放 Agent | 企业执行型 Agent |
| --- | --- | --- |
| 典型任务 | 旅行规划、文案生成 | 算薪、发薪等重业务流程交付 |
| 编排方式 | 内容生成为主，工具松编排 | 异构 API 序贯编排，参数严格绑定 |
| 错误代价 | 内容质量下降 | 交付失败甚至误操作，回滚代价巨大 |

## MCP 在企业级场景的边界

以报销流程（创建申请→上传发票→提交审批→查询结果）为例：人工操作时参数由程序固定（上传发票自然带申请 ID）；Agent 自动化时调用哪个工具、准备什么参数都由 LLM 生成，**参数漂移是常态**。MCP 标准化的是"连接方式"，不保证 LLM 生成参数的精准度——这不是 MCP 的缺陷，而是协议定位与场景需求的匹配问题。

解法：内容生成环节用 MCP 松编排；严绑定动作用**确定性绑定 + 护栏**，整体采用 Plan-and-Execute + Minimal Tool Set。

## 落地实践四件套（梁博团队）

1. **控制面/叙事面分离**：用户意图收敛为枚举结构（task/information/produce/chat）；控制平面驱动下一步逻辑，叙事平面提供推理内容；意图解析失败统一打回未知状态由兜底处理。每次推理同时产出两种信号：给人看的自然语言 + 给程序消费的结构化控制信号，每次只产出下一步。
2. **ReAct 草稿纸（Scratchpad）**：每轮 Thought/Action/Observation 作为一个 block 追加到草稿纸看板，后续步骤读 block chains 续推；任务脉络清晰后控制权交还编排器切到 Plan-and-Execute。这是团队的原创贡献，可作为双轴框架的扩展组件。
3. **Plan-and-Execute + Human-in-the-Loop**：LLM 一次性产出任务 DAG，调度器按依赖落地；组件含规划器、执行器、验收器、任务状态机；执行阶段不让 LLM 逐步重选路径。有了 DAG/状态机/调度器，对敏感操作（批量发薪、调薪基数）设阻塞点等人审即可，哪些操作人审用声明式配置。
4. **分层记忆 L1/L2/L3**：
   - L1 当前意识流 = 当前推理的最小必要输入
   - L2 里程碑日志 = "做到哪、刚完成什么"的结构化叙事，持久化到数据库
   - L3 经验教训 = 成功/失败时蒸馏，向量语义索引 + 指向 L2 原始事实的 ID
   
   L3 召回成本高，只在三个"关键边界"召回：链式推理首次、ReAct 首次、任务规划时——第一步对了，后续正确概率大增。该体系直接映射 CoALA 的 working/episodic/semantic memory，也是 MemGPT 虚拟上下文管理的最小可用实现。

## 双轴框架的实践映射

- 链式推理 = 推理 × 链式
- ReAct = 行动 × 循环
- Plan-and-Execute = 行动 × 链式
- Human-in-the-Loop = 治理 × 编排
- 分层记忆 = 记忆 × 层级

图谱不是终点而是起点——每个空白格等社区填充（草稿纸模式就可以被命名发表）。

## QA 精华

1. **AI 时代的能力重构**：行业从"模型层固化"转向"应用层爆发"；新岗位 FDE（能端到端落地的综合工程师）。硬技能：AI 应用落地、企业级系统架构、数据/知识工程；软技能：穿透迷雾看本质、知道该学什么。
2. **传统模式未失效，作用域变了**：旧模式在程序级架构仍有效，Agent 是给系统增加新变量——是扩充增强，不是推倒重来。（读者纠偏了作者一度"旧模式崩盘"的说法。）
3. **双轴框架诞生记**：半年闭关读经典 → 中文版《Agent 设计模式》 → 投稿 Manning → 会议前一天晚上顿悟双轴框架 → 英文版《Designing AI Agents》经 20 多位 Google/Microsoft/OpenAI 专家评审获 4.5 分，进入 Manning trending titles。动力："为什么模式都是外国人命名的？中国工程师要定义自己的框架。"
4. **生产级三考量**：Token 预算控制（不同模式成本差数量级）；可观测性（"一行过后即留痕"）；治理（出错回滚、权限限制——**没有治理，就没有好的 Agent**）。治理的比喻：给 Agent 完全自由 = 脱缰野马；约束催生可控的自由（就像孩子协商电视时间的例子）。

## 学习路径建议（黄佳）

先看最新的内容：优先学 Claude Code 工程化、Agent 设计模式等最新专栏，理解双轴框架和 Harness 思想，再回头补早期 ML/LangChain"边角料"。**知识会过时，但元认知不会——设计模式的底层思想 20 年也不会过时。**
