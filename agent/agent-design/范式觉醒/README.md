## 高频金句

- GoF 解决"代码怎么组织"；分布式解决"服务怎么存活"；Agent 解决"模型怎么被约束地行动"。（01）
- 模型负责花钱，Harness 负责管账。（01）
- 纵七脉定资源得失，横六式断错误路径。（02）
- 内圈让 Agent 能用，中圈让 Agent 可靠，外圈让 Agent 能上线。（02）
- 调 prompt 是局部修补；做 Harness 是把局部错误上升为系统纪律。（01）
- 模式完整的名字 = 功能 × 拓扑。（03）
- 聪明只是入场券。（05）
- 让计划活在代码里，让创意活在上下文里。（加餐）
- 知识会过时，但元认知不会。（直播回放）
