## 框架总览

双轴正交模式设计框架用两个维度对 Agent 设计模式进行分类：

- **纵轴：认知功能（七行）** —— 感知、记忆、推理、行动、反思、协作、治理，对应 Agent 的七种认知能力。
- **横轴：执行拓扑（六列）** —— 链式 Chain、路由 Route、并行 Parallel、循环 Loop、层级 Hierarchy、编排 Orchestrate，对应模式的六种执行结构。

任一模式 = 某种认知功能 × 某种执行拓扑。带 ★ 的为核心/重点模式。

## 学习路线

按认知功能逐行学习，每行内按执行拓扑从左到右（结构由简单到复杂）递进：

1. 感知 → 2. 记忆 → 3. 推理 → 4. 行动 → 5. 反思 → 6. 协作 → 7. 治理
